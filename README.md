# KET_systeem
De kleine engelse technologieschool, de KET in Brussel, wil een systeem opzetten om bedrijven te kunnen bijhouden. Het doel van dit systeem is dat ze op een snelle, overzichtelijke manier een overzicht kunnen krijgen van bedrijven die in te zetten zijn voor bv. stages, jobbeurzen, gastlessen, of sponsoring.
